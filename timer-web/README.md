# 静坐计时器 · 大屏版

参考同目录下的 Expo 计时器 App，做出的纯网页版倒计时器。无需安装任何依赖，双击 `index.html`
即可用浏览器打开使用。

## 功能

- 倒计时开始 / 暂停 / 重置
- 上下滑动「分」和「秒」滚轮，设置精确到秒的倒计时
- 快捷预设 5 / 10 / 25 / 40 分钟
- “+1 分钟”（带加时提示音）
- 音效总开关：启动提示音、每秒滴答、结束响铃、加时提示
- 显示开始时间与预计结束时间
- 电脑点击「手机遥控」出码。手机扫码后可查看剩余时间、开始、暂停、加减一分钟
- 金色主题的圆形表盘 + 进度环

## 大屏模式

点击右上角「大屏模式」进入，适合在教室、会议室的屏幕一体机上直接展示：

- 超大数字倒计时，深色高对比，远距离也清晰
- 进度环实时显示剩余时间
- 顶部标题可点击编辑（如「休息时间」「小组讨论」）
- 计时结束时闪烁「时间到！」并自动播响铃
- 底部控件栏几秒后自动隐藏，动一下鼠标/触屏即重新出现
- 可直接进入浏览器全屏（大屏模式会尝试自动全屏）

## 快捷键

| 按键 | 作用 |
| --- | --- |
| 空格 / 回车 | 开始 / 暂停 |
| R | 重置 |
| + | +1 分钟 |
| M | 声音开关 |
| F | 全屏 / 退出全屏 |
| Esc | 退出大屏模式 |

## 使用方式

通过 HTTPS 首次访问后，网页、图标及当前使用的全部音频会缓存到浏览器。再次打开优先使用本地副本，并在后台通过 HTTP 条件请求检查更新，新内容在下次打开时使用。缓存完成后支持断网使用；不会为更新自动刷新正在运行的倒计时。清除网站数据会删除离线缓存。

电脑网页顶部的“添加到桌面”可在支持的浏览器中唤起应用安装；暂不支持时显示手动添加指引。
安装功能需要通过 HTTPS 网站或 localhost 访问；直接双击 HTML 仍可正常使用计时功能。

直接双击 `index.html`。如需在局域网大屏上打开，可在本目录启动一个静态服务：

```bash
python -m http.server 8080
```

然后在同一局域网的大屏浏览器中访问 `http://本机IP:8080/index.html`。

## 手机遥控服务

手机遥控页位于 `/timer/remote/`。二维码两分钟内有效，一次配对一部手机。电脑页面负责计时和播放音效，手机断线后可在原标签页重连。

服务依赖 Python 3.10+。以下命令在仓库根目录运行。

```bash
python3 -m venv .tmp/timer-remote-venv
.tmp/timer-remote-venv/bin/pip install -r timer-web/remote-service/requirements.txt
.tmp/timer-remote-venv/bin/python -B -m unittest discover -s timer-web/remote-service
TIMER_ORIGIN=https://计时器站点 .tmp/timer-remote-venv/bin/python -B timer-web/remote-service/server.py
```

服务监听 `127.0.0.1:8765`，可用 `TIMER_PORT` 调整。静态站点发布计时器页面及 `remote/` 前端文件。Nginx 将 `/timer/remote/ws` 代理到服务的同一路径，并传递 WebSocket Upgrade 头和 `X-Real-IP`。
