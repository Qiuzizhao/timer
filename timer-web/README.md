# 德育计时器 · 大屏版

参考同目录下的 Expo 计时器 App，做出的纯网页版倒计时器。无需安装任何依赖，双击 `index.html`
即可用浏览器打开使用。

## 功能

- 倒计时开始 / 暂停 / 重置
- 快捷预设：5 / 10 / 25 / 40 分钟，也可输入任意分钟数
- “+1 分钟”（带加时提示音）
- 音效总开关：启动提示音、每秒滴答、结束响铃、加时提示
- 显示开始时间与预计结束时间
- 金色主题的圆形表盘 + 进度环

## 大屏模式

点击右上角「大屏模式」进入，适合在教室、会议室的屏幕一体机上直接展示：

- 超大数字倒计时，深色高对比，远距离也清晰
- 进度环实时显示剩余时间
- 顶部标题可点击编辑（如「休息时间」「小组讨论」）
- 计时结束时闪烁「时间到！」并自动播响铃
- 底部控件栏几秒后自动隐藏，动一下鼠标/触屏即重新出现
- 可直接进入浏览器全屏（大屏模式会尝试自动全屏）

## 快捷键

| 按键 | 作用 |
| --- | --- |
| 空格 / 回车 | 开始 / 暂停 |
| R | 重置 |
| + | +1 分钟 |
| M | 声音开关 |
| F | 全屏 / 退出全屏 |
| Esc | 退出大屏模式 |

## 使用方式

直接双击 `index.html`。如需在局域网大屏上打开，可在本目录启动一个静态服务：

```bash
python -m http.server 8080
```

然后在同一局域网的大屏浏览器中访问 `http://本机IP:8080/index.html`。
